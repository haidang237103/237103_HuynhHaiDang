## 1. Mô tả ứng dụng
Hệ thống quản lý nhân sự cho phép xem danh sách nhân viên, thêm mới, tìm kiếm, cập nhật và xóa hồ sơ nhân viên.

## 2. Công nghệ sử dụng
- **Frontend:** React, Axios
- **Backend:** Node.js, Express, Mongoose
- **Database:** MongoDB Atlas
- **DevOps:** Docker, Docker Hub, Render, Git/GitHub

## 3. Hướng dẫn chạy cục bộ (Development)
1. Backend: `cd backend && npm install && npm start`
2. Frontend: `cd frontend && npm install && npm start`
